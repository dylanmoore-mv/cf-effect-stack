# cf-effect-stack

An agent skill for building typed Cloudflare Workers apps on Effect 4 + effect-cf, React Router,
Hyperdrive + Drizzle + Postgres, Terraform-owned infra, strict TypeScript, Oxlint with anti-slop,
and one `pnpm check` gate in CI.

Start with [`SKILL.md`](SKILL.md). `references/` holds the detail; `assets/` holds config to copy
into a new project.

## Install

Copy this folder into your agent's skills directory, for example `~/.claude/skills/cf-effect-stack/`.
